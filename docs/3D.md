# 3D scene

Built with [React Three Fiber](https://r3f.docs.pmnd.rs/), [drei](https://drei.docs.pmnd.rs/) and [@react-three/postprocessing](https://react-postprocessing.docs.pmnd.rs/).

## How it's wired

`Hero` → `HeroScene` (client, `dynamic(..., { ssr: false })`) → `HeroCanvas` (`<Canvas>`, post effects, perf monitor) → `Studio` (lights + environment) and `BeadArches` (the sculpture).

- The canvas sits in the top ~64vh of the hero; a gradient fades it into the page.
- It stops rendering when the hero scrolls out of view (IntersectionObserver → `frameloop="never"`).
- `PerformanceMonitor` drops the pixel ratio from 1.5 to 1 on slow GPUs. Phones get fewer beads (`lowDetail`).
- `prefers-reduced-motion` disables the entrance, breathing and ripple.

## The sculpture (`BeadArches.tsx`)

- Each arch is a Catmull-Rom curve (`ARCH_PATH`). Along it, rings of beads are placed using Frenet frames; alternate rings are offset half a bead.
- All beads (~3,800) are one `InstancedMesh` → a single draw call. Instance matrices are written directly into the buffer each frame for the ripple.
- Tweak: `ARCHES` (positions/scale/tilt), `RING_RADIUS`, `BEAD_RADIUS`, `RIPPLE`, ring/bead counts in `buildInstances(...)`.
- Material and light colours: `siteConfig.scene` in `src/config/site.ts`.

## Lighting (`Studio.tsx`)

`<Environment>` built from `<Lightformer>` softboxes (no HDR download) gives realistic reflections. A key light follows the mouse so highlights travel across the beads. A faint coral rim light ties the 3D to the accent colour.

## Swapping in a model

1. Export `.glb` (Blender: File → Export → glTF Binary; Unity: *UnityGLTF* package). Optimise: `npx gltf-transform optimize in.glb out.glb --compress draco`.
2. Put it in `public/models/`.
3. `npx gltfjsx public/models/scene.glb -t -o src/components/canvas/Model.tsx`
4. Render `<Model />` inside `HeroCanvas` (wrap in `<Suspense>`), and `useGLTF.preload(...)`.

## Performance checklist

- Measured ~46 fps on an Intel Iris Plus 645 (weak integrated GPU) at 1440×900; dedicated/Apple GPUs hold 60.
- Avoid `setState` in `useFrame`; mutate refs.
- Keep post effects light (currently Noise + Vignette).
- Turn the scene off entirely: `siteConfig.scene.enabled = false`.
